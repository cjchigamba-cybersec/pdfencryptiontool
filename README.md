# pdfencryptiontool
 CLI tool to password-protect PDF files using AES encryption — built with pypdf.

 A simple command-line utility that encrypts PDF files with a user-supplied password.
Accepts arguments directly via CLI or falls back to interactive prompts.Built with pypdf,no external dependencies beyond the standard library.Part of a Python security tooling project at Inlighnx Global.
For authorized use only.
